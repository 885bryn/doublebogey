# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the initial single-APK Android shell with runtime Camera and Display roles.

**Architecture:** A single Gradle Android app module hosts one `MainActivity`. The activity shows a role selector, remembers the last selected role in `SharedPreferences`, and routes to simple placeholder screens for Camera and Display so both role entry points are reachable on-device.

**Tech Stack:** Kotlin, Android Gradle Plugin 8.2.1, Android SDK 36, minSdk 30, Android platform Views.
